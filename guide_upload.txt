콩콩 미션 - 파일 구조와 올리는 방법
=====================================

1. 폴더 구조 (압축을 풀어 그대로 GitHub에 올려요)
-------------------------------------------------
index.html          화면 뼈대 + 업데이트 번호(APP_BUILD)
css/style.css       디자인
js/core.js          저장, 미션, 도감, 부모 설정
js/schedule.js      일정, 달력, 알림
js/chat.js          가족방(메시지)
js/sync.js          가족 공유(동기화)
js/tools.js         일정 붙여넣기, 퀴즈, 음악, 시작 화면
js/extras.js        장보기, 칭찬 스티커, 소원 상자, 일정 수정
js/fun.js           인형 친구, 뽑기, 게임, 돌보기, 목소리
js/main.js          소원 미션 카드, 오늘 고정, 시작 처리

그대로 두는 파일(건드리지 마세요)
images 폴더, sw.js, manifest.json, icon 파일들


2. 처음 한 번 올리는 방법
-------------------------
1) GitHub 저장소(genie_showday.kr)에 들어가요.
2) index.html 을 새 파일로 교체해요.
3) css 폴더, js 폴더를 새로 추가해요.
   (Add file > Upload files 에서 폴더째 끌어다 놓으면 돼요)
4) Commit changes 를 눌러요.
5) Vercel > Deployments 에서 맨 위가 Ready 가 될 때까지 기다려요.
6) 폰의 콩콩 미션 앱을 완전히 닫았다가 다시 열어요.
7) 시작 화면의 "마지막 업데이트" 가 새 번호(예: 2026-10-08 #2)면 성공이에요.

주의: index.html 만 올리고 js 폴더를 빠뜨리면 앱이 열리지 않아요.
      그럴 때는 GitHub 화면을 캡처해서 보내 주세요.


3. 앞으로 수정할 때
-------------------
- 고친 파일만 올리면 돼요.
  예) 일정만 고치면 js/schedule.js 와 index.html, 두 개만 올려요.
- index.html 에 있는 업데이트 번호(APP_BUILD)가 바뀌어야
  폰이 새 파일을 확실히 받아요. 이 부분은 Claude가 항상 같이 바꿔 드려요.


4. 업데이트가 안 된 것 같을 때
------------------------------
1) 시작 화면의 "🔄 업데이트 확인하기" 버튼을 눌러요.
   - "최신 버전이에요" 가 나오면 이미 최신이에요.
   - 새 버전이 있으면 자동으로 받아서 다시 열려요.
2) 그래도 옛 화면이면 Vercel 이 Ready 인지 확인해요.
3) 마지막 방법: 바탕화면 바로가기를 지우고, 크롬에서 genie.showday.kr 을 열어
   "홈 화면에 추가"를 다시 해요. (데이터는 가족 코드로 다시 불러올 수 있어요)
   가족 코드는 꼭 따로 적어 두세요.
